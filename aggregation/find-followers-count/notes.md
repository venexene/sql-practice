# Find Followers Count

## Инсайт

Каждая строка `Followers` описывает связь между пользователем и его подписчиком. Нужно сгруппировать эти связи по пользователю и посчитать их количество, после чего отсортировать результат по идентификатору пользователя.

## Решение

### GROUP BY + COUNT + ORDER BY

```sql
SELECT user_id, COUNT(*) as followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id;
```

`GROUP BY user_id` собирает подписчиков каждого пользователя в отдельную группу. `COUNT(*)` считает строки группы, а `ORDER BY user_id` выводит пользователей по возрастанию идентификатора.

## Почему достаточно COUNT(*)

По условию пара `user_id` и `follower_id` является первичным ключом. Один подписчик не может повторяться у одного пользователя, поэтому число строк группы равно числу его подписчиков. Дополнительный `DISTINCT` не требуется.

## Что важно запомнить

- **Группировка выполняется по владельцу подписчиков.** Нужен `user_id`, а не `follower_id`: результат показывает, сколько подписчиков у пользователя, а не на скольких людей подписан сам подписчик.
- **COUNT(*) считает связи внутри группы.** Уникальность пары «пользователь - подписчик» гарантирует отсутствие повторного подсчёта одного подписчика у одного пользователя.
- **Один подписчик может учитываться у разных пользователей.** Уникальность гарантируется для пары, а не для `follower_id` во всей таблице.
- **ORDER BY без направления означает ASC.** Сортировка по возрастанию здесь обязательна по условию.
- **GROUP BY сам по себе не гарантирует порядок результата.** Для требуемой сортировки нужен отдельный `ORDER BY`.
- **Псевдоним followers_count задаёт требуемое имя выходной колонки.**
- **Группы формируются только из существующих записей.** Пользователь без строк в `Followers` не появится в результате; отдельный список всех пользователей эта задача не предоставляет.
