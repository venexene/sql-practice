# Number of Unique Subjects Taught by Each Teacher

## Инсайт

Один преподаватель может вести один и тот же предмет в нескольких подразделениях. Нужно посчитать не количество записей о преподавании, а количество разных предметов каждого преподавателя. Для этого подходит `COUNT(DISTINCT subject_id)` внутри группировки по `teacher_id`.

## Решение

### GROUP BY + COUNT(DISTINCT)

```sql
SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id;
```

`GROUP BY` собирает записи каждого преподавателя в отдельную группу. Агрегат считает уникальные идентификаторы предметов внутри этой группы, независимо от подразделения.

## Что важно запомнить

- **COUNT(*) и COUNT(DISTINCT) отвечают на разные вопросы.** Первый считает строки, второй - разные значения указанной колонки.
- **Уникальность проверяется внутри каждой группы.** Один предмет может учитываться у нескольких преподавателей, но у каждого из них считается только один раз.
- **dept_id не должен участвовать в группировке.** Иначе результат содержал бы отдельные строки для подразделений, а требуется одна строка на преподавателя.
- **Повторение предмета в разных подразделениях не увеличивает счётчик.** Например, два подразделения с одним предметом дают один уникальный предмет, а не два.
- **DISTINCT внутри агрегата отличается от SELECT DISTINCT.** Здесь нужно убрать повторения предметов до подсчёта, а не повторяющиеся строки итогового результата.
- **Псевдоним cnt задаёт требуемое имя выходной колонки.**
- **Сортировка по условию не требуется.** Результат можно вернуть в любом порядке.
