# Project Employees I

## Инсайт

Таблица `Project` связывает проекты с сотрудниками, а стаж каждого сотрудника хранится в `Employee`. Нужно присоединить сведения о сотрудниках и вычислить средний стаж отдельно для каждого проекта.

## Решение

### JOIN + AVG

```sql
SELECT p.project_id, ROUND(AVG(e.experience_years), 2) AS average_years
FROM Project p
JOIN Employee e ON p.employee_id = e.employee_id
GROUP BY p.project_id;
```

Соединение добавляет стаж к каждой записи участия сотрудника в проекте. `AVG` вычисляет средний стаж участников каждого проекта, а `ROUND` округляет результат до двух знаков после запятой.

## Что важно запомнить

- **Группировка задаёт уровень результата.** `GROUP BY p.project_id` формирует одну строку со средним стажем для каждого проекта.
- **Каждый участник проекта вносит один стаж в среднее.** Пара `project_id` и `employee_id` уникальна по условию, поэтому один сотрудник не учитывается в одном проекте повторно.
- **Один сотрудник может участвовать в нескольких проектах.** Его стаж должен учитываться отдельно в каждом из них.
- **AVG прямо выражает вычисление среднего.** Он заменяет ручное суммирование и деление на количество значений.
- **AVG игнорирует NULL.** Здесь стаж не содержит `NULL` по условию, поэтому в среднем участвуют все сотрудники проекта.
- **Тип результата агрегата зависит от СУБД.** В PostgreSQL среднее целочисленных значений имеет тип `numeric` и сохраняет дробную часть.
- **Округляется итоговое среднее.** По условию нужны два знака после запятой и выходная колонка `average_years`.
- **Защитные конструкции стоит выбирать по ограничениям задачи.** `LEFT JOIN`, `NULLIF` и `COALESCE` полезны при соответствующих крайних случаях, но не обязательны в каждом запросе.
