# Classes with at Least 5 Students

## Инсайт

Нужно объединить записи по классу и оставить только те классы, в которых учатся не менее пяти студентов. Условие зависит от количества записей внутри группы, поэтому применяется через `HAVING`, а не через `WHERE`.

## Решение

### GROUP BY + HAVING

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(*) >= 5;
```

`GROUP BY class` собирает студентов каждого класса в отдельную группу. `COUNT(*)` считает строки внутри группы, а `HAVING` оставляет классы с количеством студентов от пяти включительно.

## Почему достаточно COUNT(*)

По условию пара `student` и `class` является первичным ключом. Один студент не может встретиться в одном классе повторно, поэтому каждая строка группы соответствует отдельному студенту. `COUNT(*)` даёт нужное количество без дополнительного `DISTINCT`. Если бы повторные записи были допустимы, для подсчёта разных студентов потребовался бы `COUNT(DISTINCT student)`.

## Что важно запомнить

- **WHERE фильтрует строки, HAVING - группы.** Проверка результата `COUNT` относится к группе и записывается в `HAVING`.
- **Не менее пяти означает >= 5.** Класс ровно с пятью студентами тоже должен попасть в результат.
- **Подсчёт выполняется отдельно для каждого класса.** Один студент может учитываться в нескольких классах, если записан в каждый из них.
- **Нужен только класс, а не сам счётчик.** Агрегат можно использовать в `HAVING`, не выводя его в `SELECT`.
- **DISTINCT следует выбирать с учётом ограничений схемы.** Уникальность пары «студент - класс» уже исключает повторные записи внутри группы.
- **Сортировка по условию не требуется.** Подходящие классы можно вернуть в любом порядке.
