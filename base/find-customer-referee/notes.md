# Find Customer Referee

## Инсайт

Главная ловушка — `NULL`. Нельзя просто написать `referee_id != 2`, потому что `NULL != 2` возвращает `NULL` (не `TRUE`), и такие строки выпадают из результата. Нужно явно обработать `NULL` через `IS NULL`.

## Решение

### WHERE с IS NULL и != — O(n), O(1)

```sql
SELECT name
FROM Customer
WHERE referee_id IS NULL OR referee_id != 2;
```

Явно включаем покупателей без реферера (`IS NULL`) и тех, у кого реферер не равен 2.

## Что важно запомнить

- **NULL — не значение, а отсутствие значения.** Любое сравнение с `NULL` даёт `NULL`, а не `TRUE`/`FALSE`. В `WHERE` проходят только строки с `TRUE`
- **Типичная ошибка:** `WHERE referee_id != 2` — неявно исключает всех, у кого `referee_id IS NULL`
- **Альтернатива — COALESCE:** можно обернуть: `WHERE COALESCE(referee_id, 0) != 2`, но `IS NULL OR` читается понятнее и не зависит от магического числа
- **Трёхзначная логика SQL:** `TRUE`, `FALSE`, `NULL`. Всегда помни про третий вариант, когда в колонке могут быть `NULL`-ы
