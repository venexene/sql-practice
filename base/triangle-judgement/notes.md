# Triangle Judgement

## Инсайт

Три длины образуют треугольник, если сумма любых двух сторон строго больше третьей. Нужно проверить все три условия и для каждой исходной строки добавить ответ `Yes` или `No`, сохранив значения сторон.

## Решение

### CASE с тремя неравенствами

```sql
SELECT *, CASE
            WHEN (x + y > z) AND (x + z > y) AND (y + z > x) THEN 'Yes'
            ELSE 'No'
          END AS triangle
FROM Triangle;
```

`CASE` проверяет, выполняются ли одновременно три неравенства. Если да, вычисляемая колонка `triangle` получает значение `Yes`, иначе - `No`. `SELECT *` возвращает исходные колонки `x`, `y` и `z`.

## Что важно запомнить

- **Неравенства строгие.** Если сумма двух сторон равна третьей, получается вырожденная фигура, а не треугольник. Например, длины 1, 2 и 3 должны дать `No`.
- **Проверяются все три стороны.** Порядок значений не гарантирует, что какая-то конкретная колонка содержит самую длинную сторону.
- **Условия соединяются через AND.** Для существования треугольника должны выполняться все неравенства, а не хотя бы одно.
- **CASE вычисляет значение, а WHERE фильтрует строки.** Здесь нужно отметить каждую строку, поэтому исключать неподходящие длины через `WHERE` нельзя.
- **ELSE задаёт ответ для неподходящих длин.** Без него результат `CASE` при невыполнении условия был бы `NULL`.
- **Псевдоним triangle задаёт требуемое имя выходной колонки.** Значения `Yes` и `No` также соответствуют формату условия.
- **Сортировка по условию не требуется.** Строки можно вернуть в любом порядке.
