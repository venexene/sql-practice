# Exchange Seats

## Инсайт

Нужно поменять местами студентов в соседних парах: место 1 с местом 2, место 3 с местом 4 и так далее. Сами идентификаторы мест остаются прежними, меняется только имя студента в выводе.

Для нечётного места нужен студент из следующей строки, а для чётного - из предыдущей. Это напрямую выражается через оконные функции `LEAD` и `LAG`.

## Решение

### CASE + LAG/LEAD + COALESCE

```sql
SELECT
    id,
    COALESCE(
        CASE
            WHEN id % 2 = 0 THEN LAG(student) OVER(ORDER BY id)
            ELSE LEAD(student) OVER(ORDER BY id)
        END
    ,student) AS student
FROM Seat
ORDER BY id;
```

`CASE` определяет направление обмена по чётности места. Для чётного `id` берётся студент из предыдущей строки, для нечётного - из следующей. `COALESCE` возвращает исходное имя, если соседней строки нет, а внешний `ORDER BY` сохраняет порядок мест.

## Как работает перестановка

| id | Исходный студент | Используемая функция | Студент в результате |
|---|---|---|---|
| 1 | A | LEAD | B |
| 2 | B | LAG | A |
| 3 | C | LEAD | D |
| 4 | D | LAG | C |
| 5 | E | LEAD даёт NULL | E через COALESCE |

Последнее нечётное место не имеет пары, поэтому студент остаётся на нём без изменений.

## Два назначения ORDER BY

- `ORDER BY id` внутри `OVER` определяет соседние строки для `LAG` и `LEAD`.
- Финальный `ORDER BY id` определяет порядок строк результата.

Порядок окна сам по себе не гарантирует порядок вывода, поэтому обе конструкции выполняют отдельную роль.

## Что важно запомнить

- **Меняется значение student, а не id.** Места остаются пронумерованы как в исходной таблице.
- **Чётность определяет направление.** Нечётное место получает следующего студента, чётное - предыдущего.
- **LEAD и LAG работают со строками в заданном порядке.** Они не вычисляют идентификатор соседнего места самостоятельно.
- **Решение опирается на условие задачи.** Идентификаторы начинаются с 1, идут непрерывно и уникальны, поэтому соседняя строка соответствует соседнему месту.
- **COALESCE обрабатывает непарное последнее место.** `LEAD` возвращает `NULL`, и сохраняется исходное имя.
- **student не содержит NULL по условию.** Поэтому `NULL` от `LEAD` однозначно означает отсутствие следующей строки, а не отсутствующее имя соседа.
- **Оконные функции не сворачивают строки.** Каждое место остаётся отдельной строкой, к которой добавляется значение соседа.
- **Подзапрос не нужен.** Результаты оконных функций используются непосредственно в выходном выражении, а не в `WHERE`.
- **Сортировка результата обязательна.** По условию строки должны быть возвращены по возрастанию `id`.
