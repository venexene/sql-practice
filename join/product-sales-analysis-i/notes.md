# Product Sales Analysis I

## Инсайт

Таблица `Sales` содержит сведения о продаже, включая год и цену, но вместо названия товара хранит только `product_id`. Название находится в таблице `Product`, поэтому нужно соединить таблицы по общему идентификатору товара.

## Решение

### JOIN по product_id

```sql
SELECT p.product_name, s.year, s.price
FROM Sales s
JOIN Product p ON s.product_id = p.product_id;
```

Каждая строка `Sales` сопоставляется с соответствующим товаром из `Product`. Из продажи берутся год и цена, а из связанной записи товара — его название.

## Что важно запомнить

- **Соединение дополняет данные из связанной таблицы.** В `Sales` есть идентификатор товара, а `JOIN` позволяет получить по нему `product_name`.
- **Условие соединения строится по связанным ключам.** `Sales.product_id` ссылается на `Product.product_id`.
- **Одна строка товара может соответствовать нескольким продажам.** Поэтому название одного товара закономерно может появиться в результате несколько раз.
- **`DISTINCT` здесь не нужен.** Даже одинаковые значения названия, года и цены могут относиться к разным строкам продаж, которые не следует случайно удалять.
- **Обычный `JOIN` подходит по условию задачи.** Каждая продажа относится к существующему товару, поэтому сохранять продажи без найденного продукта не требуется.
- **Сортировка не нужна, если её явно не требует условие.** Без `ORDER BY` порядок строк результата не определён, но для этой задачи он не имеет значения.
