# Customer Who Visited but Did Not Make Any Transactions

## Инсайт

Нужно найти посещения, для которых не существует ни одной связанной транзакции, а затем посчитать такие посещения для каждого клиента. Это задача на анти-джойн: сохраняем все строки из `Visits`, присоединяем `Transactions` и отбираем случаи, где совпадение не нашлось.

## Решение

### LEFT JOIN + IS NULL + GROUP BY

```sql
SELECT v.customer_id, COUNT(*) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t ON v.visit_id = t.visit_id
WHERE t.transaction_id IS NULL
GROUP BY v.customer_id;
```

`LEFT JOIN` сохраняет каждое посещение. Если у посещения нет транзакций, колонки присоединённой таблицы получают `NULL`. После фильтрации каждая оставшаяся строка соответствует одному посещению без транзакций, поэтому их можно сгруппировать и посчитать по `customer_id`.

## Альтернатива

То же условие можно выразить через `NOT EXISTS`: оставить посещение, для которого не существует строки в `Transactions` с таким же `visit_id`. Этот вариант прямо передаёт смысл задачи, а выбор плана выполнения остаётся за оптимизатором.

## Что важно запомнить

- **Связь строится по `visit_id`.** Транзакция относится к конкретному посещению, а не напрямую к клиенту.
- **Проверять `NULL` нужно по колонке правой таблицы.** Отсутствие значения `transaction_id` после `LEFT JOIN` означает, что связанная транзакция не найдена.
- **Фильтрация выполняется до группировки.** Сначала удаляются посещения с транзакциями, затем оставшиеся строки считаются по клиентам.
- **`COUNT(*)` здесь корректен.** После `WHERE` каждая строка результата соединения уже представляет одно посещение без транзакций.
- **Несколько посещений одного клиента должны считаться отдельно.** Поэтому группировка выполняется по `customer_id`, а считается количество оставшихся строк.
- **Клиенты без подходящих посещений не выводятся.** Это соответствует условию: результат содержит только клиентов, которые хотя бы раз посетили магазин без транзакции.
