# Invalid Tweets

## Инсайт

Нужно вернуть идентификаторы твитов, длина текста которых превышает допустимый предел. Главный момент — строгое сравнение: твит из 15 символов ещё считается допустимым, а недопустимым становится только текст длиннее 15 символов.

## Решение

### Фильтрация по длине строки

```sql
SELECT tweet_id
FROM Tweets
WHERE length(content) > 15;
```

Функция `length` вычисляет длину содержимого, после чего `WHERE` оставляет только строки, превышающие ограничение.

## Что важно запомнить

- **Граница не включается.** По условию недопустима длина больше 15, поэтому используется строгое сравнение `>`, а не `>=`.
- **Строковые функции можно использовать в `WHERE`.** Для каждой строки сначала вычисляется длина `content`, затем проверяется условие фильтрации.
- **Выбирать нужно только требуемые колонки.** В результате нужен идентификатор твита, поэтому возвращается только `tweet_id`.
- **Функции длины зависят от диалекта SQL.** В PostgreSQL `length` возвращает количество символов строки. В других СУБД стоит различать длину в символах и длину в байтах, особенно для многобайтового текста.
