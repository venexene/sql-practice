# Primary Department for Each Employee

## Инсайт

Нужно обработать два случая: у сотрудника с несколькими отделами выбрать отдел с `primary_flag = 'Y'`, а у сотрудника с одним отделом вернуть этот единственный отдел, даже если его флаг равен `N`. Эти случаи удобно выразить двумя запросами и объединить результаты.

## Решение

### Фильтрация + UNION ALL + GROUP BY с HAVING

```sql
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'
UNION ALL
SELECT employee_id, MAX(department_id)
FROM Employee
GROUP BY employee_id
HAVING COUNT(*) = 1;
```

Первая часть возвращает отделы, явно отмеченные как основные. Вторая группирует записи по сотруднику и оставляет только группы с одной строкой. `MAX(department_id)` извлекает идентификатор единственного отдела из такой группы.

## Почему MAX здесь корректен

После проверки `COUNT(*) = 1` группа содержит ровно одну запись. Поэтому `MAX` возвращает её `department_id`; `MIN` дал бы тот же результат. Агрегат используется для получения значения из группы, а не для определения основного отдела по величине идентификатора.

Если убрать ограничение на размер группы, выбор максимального идентификатора уже не соответствовал бы условию задачи.

## Почему используется UNION ALL

По условию у сотрудника с единственным отделом флаг равен `N`, поэтому он не попадает в первую часть. Две части не пересекаются, а повторные пары внутри них исключены ограничениями задачи. Поэтому `UNION ALL` объединяет результаты без ненужного удаления дублей.

`UNION` дал бы тот же ответ, но дополнительно удаляет одинаковые строки. `UNION ALL` сохраняет все строки обеих частей; здесь это соответствует требуемому результату.

## Что важно запомнить

- **Одного фильтра по Y недостаточно.** Он потерял бы сотрудников с единственным отделом, у которых флаг равен `N`.
- **HAVING проверяет количество отделов сотрудника.** Группировка выполняется по `employee_id`, а условие оставляет группы с одной строкой.
- **COUNT(*) соответствует количеству отделов.** Пара `employee_id` и `department_id` является первичным ключом, поэтому один отдел не повторяется у одного сотрудника.
- **Агрегат может извлекать единственное значение группы.** Здесь `MAX(department_id)` корректен благодаря ограничению на размер группы.
- **Обе части UNION ALL должны возвращать совместимые колонки.** В этом запросе сначала идёт идентификатор сотрудника, затем идентификатор отдела.
- **Имена колонок объединённого результата задаёт первая часть.** Выходные колонки называются `employee_id` и `department_id`, хотя во второй части используется агрегат без псевдонима.
- **Сортировка по условию не требуется.** Результат можно вернуть в любом порядке.
