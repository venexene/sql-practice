# Biggest Single Number

## Инсайт

Нужно найти наибольшее число среди тех, которые встречаются в таблице ровно один раз. Это два этапа: сначала сгруппировать одинаковые числа и отобрать группы размером один, затем вычислить максимум среди оставшихся значений.

## Решение

### GROUP BY + HAVING в подзапросе + MAX

```sql
SELECT MAX(num) AS num
FROM
    (SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1);
```

Подзапрос возвращает только числа, у которых ровно одна запись в `MyNumbers`. Внешний `MAX` выбирает наибольшее из них и задаёт имя выходной колонки `num`.

## Почему внешний MAX важен

Если подходящих чисел нет, подзапрос возвращает пустой набор. Агрегат `MAX` без `GROUP BY` всё равно возвращает одну строку, содержащую `NULL`. Именно такой результат требуется по условию, а не отсутствие строк.

Сортировка по убыванию с ограничением одной строкой могла бы выбрать максимум, но при пустом наборе сама по себе не обеспечила бы строку с `NULL`.

## Совместимость подзапроса без псевдонима

В текущем решении подзапрос в `FROM` не имеет псевдонима. Это допустимо начиная с [PostgreSQL 16](https://www.postgresql.org/docs/16/release-16.html). В [PostgreSQL 15](https://www.postgresql.org/docs/15/queries-table-expressions.html#QUERIES-FROM-SUBQUERIES) псевдоним обязателен. Для совместимости с более старыми версиями стоит присвоить подзапросу имя.

## Что важно запомнить

- **Встретиться один раз и быть уникальным после DISTINCT - разные вещи.** `DISTINCT` убирает повторы, но не позволяет отличить число с одной записью от числа с несколькими.
- **HAVING проверяет частоту внутри группы.** Условие `COUNT(*) = 1` оставляет только числа, встречающиеся ровно один раз.
- **Отбор выполняется до поиска максимума.** Максимальное число всей таблицы может встречаться несколько раз и не подходить.
- **Два уровня агрегации отвечают на разные вопросы.** Внутренний подсчёт определяет частоту числа, внешний максимум выбирает ответ среди подходящих чисел.
- **MAX по пустому набору возвращает NULL.** Внешний запрос без группировки сохраняет требуемую форму результата: одну строку с ответом.
- **COALESCE здесь не нужен.** Если подходящих чисел нет, условие требует именно `NULL`, а не ноль или другое значение.
- **MAX подходит и для отрицательных чисел.** Не нужно вводить ноль как начальное или запасное значение максимума.
