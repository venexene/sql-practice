# Monthly Transactions I

## Инсайт

Нужно построить отчёт для каждой пары «месяц — страна»: посчитать все транзакции и их общую сумму, а также отдельно количество и сумму одобренных транзакций. Все показатели можно вычислить в одной группировке, ограничивая нужные агрегаты через `FILTER`.

## Решение

### Группировка по месяцу и стране + FILTER

```sql
SELECT
    TO_CHAR(trans_date, 'YYYY-MM') as month,
    country,
    COUNT(*) AS trans_count,
    COUNT(*) FILTER(WHERE state = 'approved') AS approved_count,
    SUM(amount) AS trans_total_amount,
    COALESCE(SUM(amount) FILTER(WHERE state = 'approved'), 0) AS approved_total_amount
FROM Transactions
GROUP BY TO_CHAR(trans_date, 'YYYY-MM') , country
```

`TO_CHAR` преобразует дату в строку вида `YYYY-MM`. Группировка объединяет транзакции одного месяца и одной страны. Обычные агрегаты учитывают все строки группы, а агрегаты с `FILTER` — только строки со статусом `approved`.

## Почему COALESCE нужен только для одобренной суммы

В сформированной группе есть хотя бы одна транзакция, но одобренных транзакций может не быть. В таком случае отфильтрованный `COUNT(*)` возвращает `0`, а отфильтрованный `SUM(amount)` — `NULL`. `COALESCE` заменяет отсутствующую сумму на требуемый ноль.

## Что важно запомнить

- **Группировка определяет детализацию отчёта.** Каждая строка результата соответствует одной паре «месяц — страна».
- **В месяц нужно включать год.** Группировка только по номеру месяца объединила бы, например, январь разных лет.
- **TO_CHAR задаёт требуемый формат.** Выходная колонка `month` содержит год и месяц без дня.
- **FILTER действует только на свой агрегат.** Подсчёты и суммы без фильтра продолжают учитывать все транзакции.
- **WHERE со статусом approved здесь не подходит.** Он удалил бы остальные транзакции до группировки и исказил общие количество и сумму.
- **COUNT и SUM по пустому набору ведут себя по-разному.** Первый возвращает `0`, второй — `NULL`.
- **NULL в country не требует исключения.** Транзакции с отсутствующей страной объединяются в соответствующую группу своего месяца.
- **TO_CHAR и FILTER подходят для PostgreSQL.** В другой СУБД синтаксис форматирования даты и условной агрегации может отличаться.
- **Сортировка по условию не требуется.** Строки отчёта можно вернуть в любом порядке.
