# Article Views I

## Инсайт

Нужно найти авторов, которые просматривали собственные статьи. Такая строка определяется равенством `author_id` и `viewer_id`. Один автор мог сделать это несколько раз или просмотреть несколько своих статей, поэтому в результате каждый идентификатор должен остаться только один раз.

## Решение

### Фильтрация + GROUP BY

```sql
SELECT author_id AS id
FROM Views
WHERE author_id = viewer_id
GROUP BY author_id
ORDER BY author_id;
```

Сначала оставляем только самопросмотры. Затем группируем строки по автору, чтобы убрать повторения, переименовываем выходную колонку в `id` и сортируем идентификаторы по возрастанию.

## Альтернатива

Для удаления повторений здесь также подходит `DISTINCT`. Он точнее выражает намерение получить уникальные значения, тогда как `GROUP BY` чаще используют вместе с агрегатными функциями. Оба варианта дают одинаковый результат.

## Что важно запомнить

- **Сравнивать можно колонки одной строки.** Условие `author_id = viewer_id` проверяет, является ли зритель автором статьи.
- **После фильтрации возможны дубликаты.** Один автор может встретиться в таблице несколько раз, поэтому одной конструкции `WHERE` недостаточно.
- **`GROUP BY` без агрегатных функций удаляет повторы по колонкам группировки.** В этой задаче он работает как получение уникальных авторов.
- **Псевдоним задаёт имя выходной колонки.** По условию результат должен содержать колонку `id`.
- **Порядок строк гарантирует только `ORDER BY`.** Без него СУБД может вернуть идентификаторы в произвольном порядке.
