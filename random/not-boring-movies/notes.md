# Not Boring Movies

## Инсайт

Нужно выбрать фильмы, которые одновременно имеют нечётный идентификатор и описание, отличное от `boring`. После фильтрации результат требуется отсортировать по рейтингу в порядке убывания.

## Решение

### WHERE с AND + ORDER BY

```sql
SELECT *
FROM Cinema
WHERE id % 2 != 0 AND description != 'boring'
ORDER BY rating DESC;
```

Оператор `%` вычисляет остаток от деления идентификатора на 2. Ненулевой остаток означает, что идентификатор нечётный. Второе условие исключает фильмы с описанием `boring`, а сортировка располагает оставшиеся фильмы от самого высокого рейтинга к самому низкому.

## Что важно запомнить

- **Проверка нечётности через остаток.** Если число не делится на 2 без остатка, оно нечётное.
- **`AND`, а не `OR`.** Фильм должен удовлетворять обоим условиям: иметь нечётный идентификатор и подходящее описание.
- **`DESC` задаёт убывающий порядок.** Без него `ORDER BY` по умолчанию сортирует по возрастанию.
- **Фильтрация и сортировка решают разные задачи.** `WHERE` определяет, какие строки попадут в результат, а `ORDER BY` — в каком порядке они будут показаны.
- **`SELECT *` подходит к требуемому результату этой задачи.** Нужно вернуть все колонки таблицы `Cinema`. Если требуется только часть колонок, лучше перечислить их явно.
