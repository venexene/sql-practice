# Fix Names in a Table

## Инсайт

Имя нужно разделить на две части и обработать их независимо:

1. первый символ перевести в верхний регистр;
2. все символы начиная со второго перевести в нижний регистр.

После этого обе части можно объединить оператором конкатенации `||`.

## Решение

### LEFT + SUBSTRING + изменение регистра

```sql
SELECT
    user_id,
    UPPER(LEFT(name, 1)) || LOWER(SUBSTRING(name FROM 2)) AS name
FROM Users
ORDER BY user_id;
```

`LEFT(name, 1)` извлекает первый символ имени, а `UPPER` переводит его в верхний регистр. `SUBSTRING(name FROM 2)` возвращает оставшуюся часть строки, которую `LOWER` переводит в нижний регистр. Оператор `||` соединяет результаты в исправленное имя.

## Как преобразуется имя

| Исходное значение | Первая часть | Остальная часть | Результат |
|---|---|---|---|
| `aLice` | `A` | `lice` | `Alice` |
| `BOB` | `B` | `ob` | `Bob` |
| `c` | `C` | пустая строка | `C` |

Регистр исходных символов не имеет значения, потому что обе части явно проходят через `UPPER` или `LOWER`.

## Почему имя из одного символа работает

Для односимвольного имени `LEFT(name, 1)` возвращает этот символ, а `SUBSTRING(name FROM 2)` - пустую строку. Конкатенация заглавной первой буквы с пустой строкой даёт правильный результат без отдельного условия.

## Зачем нужен ORDER BY

По условию строки должны быть возвращены по возрастанию `user_id`. Без внешнего `ORDER BY user_id` порядок результата не гарантирован, даже если строки в таблице физически расположены в нужной последовательности.

## Что важно запомнить

- **Разные части строки можно преобразовывать отдельно.** Это удобно, когда правила для первого символа и остатка различаются.
- **LEFT извлекает заданное количество символов слева.** Здесь нужен ровно один символ.
- **SUBSTRING с FROM задаёт начальную позицию.** Нумерация символов начинается с единицы, поэтому остаток имени начинается с позиции 2.
- **Оператор `||` объединяет строки в PostgreSQL.** Обе обработанные части образуют итоговое имя.
- **Отдельный CASE для короткого имени не требуется.** Строковые функции естественно обрабатывают пустой остаток.
- **Сортировка результата задаётся явно.** `ORDER BY user_id` выполняет требование задачи.
